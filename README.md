# My English Lab

개인용 영어 학습 사이트 (Vanilla HTML/CSS/JS, 단일 파일).

## 기능
- 📊 **대시보드** — 스트릭, 일일 학습 시간, 14일 활동 그리드
- 📖 **독해 연습** — 샘플 지문 + 한글 해석 토글 + 단어 클릭으로 단어장 추가
- 🔗 **URL 분석** — 임의의 웹 URL을 가져와 핵심 단어/문장 추출 (CORS 프록시)
- 🗂️ **내 단어장** — LocalStorage에 누적
- ⚙️ **설정** — JSON 내보내기/가져오기, 프록시 변경, 초기화

## 사용법
`index.html`을 브라우저로 열기만 하면 됩니다. 빌드 불필요.
